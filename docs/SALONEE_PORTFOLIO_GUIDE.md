# How to turn AeroLens into Salonee's own credible portfolio

This code was initially developed with AI assistance. **An impressive-looking GitHub repository is not evidence of hands-on competence by itself.** For an honest and effective portfolio:

1. Reproduce the observed CAA 2024/2025 total for at least five selected routes from the official original table and document any differences.
2. Use the live Fleet Portfolio slider to identify which constraints bind and explain why the solution changes; independently reproduce one small example via enumeration.
3. Open the PBIP in Power BI Desktop, run model refresh and show that the DAX calculations reconcile with the CSV source; resolve any errors.
4. Add **one independent extension** (for example, a monthly CAA data importer or a new KPI with test cases) and record the commit.
5. Explain why theoretical carrier-level emissions and net fares cannot be treated as observed facts; explain what data would be needed.
6. Prepare a 3-minute case study: problem, data source, limitations, method, validation, decision and next steps.
